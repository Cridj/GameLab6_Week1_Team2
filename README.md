<h1 align="center">HOPAK SNAKE · 호팍 스네이크</h1>
<p align="center"><b>리듬 · 성장 · 멀티플레이 PvP</b></p>

호팍춤을 추며 시민을 모으고, 길어진 대열로 다른 플레이어와 경쟁하는 게임입니다. 리듬에 맞춰 콤보를 쌓고 대시로 상대를 추격하거나 위험한 순간을 빠져나옵니다.

<p align="center"><img src="docs/media/week1-growth.gif" alt="시민을 모으며 성장하는 호팍" width="800"></p>

## 어떤 게임인가요?

호팍 스네이크의 목표는 **시민을 모아 대열과 몸집을 키우고, 다른 플레이어와 경쟁하며 월드에서 가장 큰 호팍이 되는 것**입니다. 호팍춤을 추는 캐릭터들이 줄지어 따라오는 유쾌한 모습에, 상대의 이동 경로를 읽고 길을 막는 지렁이 게임의 경쟁을 더했습니다.

처음에는 주변의 시민을 모으며 몸집을 키우지만, 성장할수록 다른 플레이어를 추격하고 대열로 압박할 수 있습니다. 리듬 입력은 이 경쟁에 사용할 대시를 준비하는 행동입니다.

## 핵심 재미

### 눈에 보이는 성장과 상대를 압박하는 재미

시민을 얻을 때마다 뒤따르는 대열이 늘어나고 캐릭터의 크기와 속도도 커집니다. 숫자만 오르는 성장보다, 내 몸집과 대열이 화면을 채워 가는 변화를 직접 볼 수 있습니다. 작은 호팍으로 시작해 다른 플레이어를 내려다볼 만큼 성장하는 것이 큰 보상입니다.

### 커져도 방심할 수 없는 PvP

큰 몸집과 긴 대열은 상대의 길을 막는 데 유리하지만, 작은 상대를 놓치기 쉽습니다. 성장했다고 안전해지는 것은 아닙니다. 주변을 살피며 내 머리가 상대 대열에 닿지 않도록 움직이고, 반대로 상대가 내 대열에 부딪히도록 위치를 잡아야 합니다.

### 리듬을 유지하고 대시를 쓸 순간 고르기

A / D를 번갈아 누르며 콤보를 유지할수록 대시 게이지가 더 빠르게 충전됩니다. 채운 게이지는 상대를 따라잡는 데 쓸 수도, 위험한 대열 사이에서 빠져나오는 데 쓸 수도 있습니다. 리듬을 쌓는 행동과 추격·회피의 판단이 하나의 플레이로 이어집니다.

## 길어질수록 커지는 경쟁

초록색 시민을 모으면 대열이 길어지고 몸집도 커집니다. 상대의 머리를 내 대열에 부딪히게 만들면 상대가 남긴 시민을 모아 더 크게 성장할 수 있습니다.

## 주요 규칙

| 요소 | 플레이 방식 |
| --- | --- |
| 시민 획득 | 필드의 초록색 시민에게 접촉하면 대열에 합류합니다. 시민을 모으며 몸집과 이동 속도를 키웁니다. |
| 콤보 | A / D 리듬을 유지해 대시 게이지의 충전 속도를 높입니다. |
| 대시 | 마우스 왼쪽 버튼을 누르고 있는 동안 게이지를 소모하며 질주합니다. |
| 대열 충돌 | 상대의 머리를 내 대열에 부딪히게 만들어 처치할 수 있습니다. 내 머리도 상대 대열에 닿지 않도록 주의해야 합니다. |
| 처치 보상 | 처치된 플레이어가 모았던 시민이 그 자리에 남습니다. 이를 모아 다음 성장으로 이어갈 수 있습니다. |
| 커스터마이징 | 피부색, 신발, 액세서리를 골라 여러 호팍 사이에서도 내 캐릭터를 알아보기 쉽게 꾸밉니다. |

## 한 판의 흐름

먼저 외형과 닉네임을 정하고 필드에 들어갑니다. 주변 시민을 모으며 리듬과 이동에 익숙해진 뒤, 대시 게이지와 주변 플레이어의 위치를 보며 경쟁에 뛰어듭니다. 상대를 처치하면 남겨진 시민을 모아 더 크게 성장하고, 다시 새로운 상대를 찾아 움직입니다.

## 조작

**캐릭터 꾸미기 → 시민 모으기 → 콤보와 대시 → 다른 플레이어와 경쟁**

| 입력 | 동작 |
| --- | --- |
| A / D 번갈아 입력 | 콤보 유지 |
| 마우스 좌우 이동 | 방향 전환 |
| 마우스 왼쪽 버튼 유지 | 대시 |
| 사망 후 Space | 로비로 돌아가기 |
